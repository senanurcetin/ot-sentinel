# BATADAL evidence explorer — scope and acceptance

Route: `/batadal-explorer`. The evidence explorer is a standalone,
read-only **offline** inspection view. It does not replace the synthetic
3-sensor live demonstration on `/` or its browser-only three-sensor
`/offline-replay` workflow.

## Data provenance and capabilities

The view reads the committed `src/data/batadal-case-study/results.json`
generated by `analysis/run_batadal_case_study.py`, validated by existing
`src/lib/case-study.ts` schemas and the extra 43-feature contract in
`src/lib/batadal-explorer.ts`. The underlying pipeline uses independently
pinned original BATADAL CSV SHA-256 values in `analysis/batadal_data.py`,
published attack intervals and a reference/calibration split. The reader
sees exactly 43 feature identifiers and their typed categories: 7 tank
levels, pump flows and states, valve flows and states, junction pressures.

- Evaluation set: 2017 unseen test (attacks 8–14) or 2016 secondary dataset04
  (attacks 1–7). The supervised gradient-boosting reference is **not evaluated**
  on the 2016 set it was trained on.
- Detector: actual evaluated method (7 on test, 6 on secondary). Show real
  measured PR-AUC, hourly precision/recall, alarm fraction in attack-free
  hours, false alarms/day and expected attacks caught from false alarms alone.
- Attack descriptions: published attack-number-to-affected-feature codes,
  detector alarm outcome, reported duration and hours to first alarm. These
  target codes are **not** computed signal importance or proof of cyberattack
  detection.
- Distribution shift: reference constant-feature indicators, percentage
  of attack-free evaluation hours outside reference min/max, and only the
  published *top* drift features. A feature absent from the top-drift report
  shows **not reported**, never 0% or healthy.
- No new model inference or data uploading. The view does not include raw
  43-signal hourly traces, full raw CSVs, live PLC data or any control action.
  Do not invent reconstructed per-hour curves from the stored aggregates.

## Acceptance

- Unit tests prove all 43 identifiers are unique and grouped without loss,
  cross-check constant features, attack annotations and source-of-metrics.
- Unit/UI/E2E tests verify holdout/training separation, access, filtering,
  missing drift semantics, and clear demonstration-vs-benchmark boundaries.
- Exact-head CircleCI web-quality, analysis-quality, Chromium browser-e2e,
  plus GitHub Docker/security gates all pass before merge.
- Raw 43-signal historical time-series replay is a **separate future phase**
  requiring verified, read-only access to source CSVs, temporal validation
  and independent provenance. A full temporal chart must never be fabricated.
